### 2. The Gesture Blocker & The Two Gimbal Bugs
During our investigation across the codebase, we pinpointed three issues:
1. **`LEFT` & `RIGHT` Finger Landmark Blocker:**
   In [src_nodes/gesture_node.py](file:///home/j/ros2_cognition_ws/src_nodes/gesture_node.py), the rule classifier previously evaluated `index_up = is_ext(8, 6, 5)` which tested vertical extension ($y_{tip} < y_{pip}$). When pointing horizontally (`LEFT` or `RIGHT`), $y$ does not decrease; rather, lateral offset $\Delta x$ increases. We updated the logic to check lateral index extension (`d_index_ext > 1.35 * d_index_mcp`), but **that change was only committed to Git on the laptop and was never deployed to the robot's Docker container**.
2. **The 2 Hz Person Detection Throttling Bug:**
   In [src_nodes/active_vision_node.py](file:///home/j/ros2_cognition_ws/src_nodes/active_vision_node.py#L209), line 209 blocked person detections if `now - self.last_target_time < 0.5s`. Because `detection_callback` itself updates `self.last_target_time`, it inadvertently starved person tracking down to 2 Hz. We will separate `last_face_time` from `last_target_time` to restore full 10–20 Hz tracking.
3. **Target Loss FSM:**
   When an explicit target loss ($z \le 0$) occurs, resetting `latest_target = None` ensures immediate transition to `MEMORY_HOLD`.
