# Streamlining Web Navigation Visualizer for Physical Yahboom Micro-ROS Robot

This plan establishes architectural alignment with the **Official ROS 2 & Nav2 Documentation**, **Articulated Robotics (Josh Newans)** design principles, and **Yahboom Micro-ROS Pi 5** hardware constraints. It strips unnecessary in-canvas clutter and equips the dashboard with physical robot controls (E-Stop, live battery voltage, quick mission dispatch).

---

## 1. Grounding in Project Reference Guides

### A. ROS 2 & Nav2 Official Documentation (`navigation.ros.org` & `docs.ros.org`)
* **Standard Topic Interfaces:** The visualization layer must decouple rendering from hardcoded logic. It strictly interacts via standard ROS 2 message definitions:
  - Subscriptions: `/map` (`nav_msgs/OccupancyGrid`), `/scan` / `/scan_downsampled` (`sensor_msgs/LaserScan`), `/local_costmap/costmap` (`nav_msgs/OccupancyGrid`), `/particlecloud` (`geometry_msgs/PoseArray`), `/plan` & `/local_plan` (`nav_msgs/Path`).
  - Publications: `/goal_pose` (`geometry_msgs/PoseStamped`), `/initialpose` (`geometry_msgs/PoseWithCovarianceStamped`), `/cmd_vel` (`geometry_msgs/Twist`).
* **Nav2 Action Abort:** Operator interfaces must support emergency stopping and goal cancellation (`/cmd_vel` zero clamp and goal abort).

### B. Articulated Robotics (Josh Newans — `articulatedrobotics.xyz`)
* **Clean Engineering Display:** Josh's fundamental rule for mobile robot visualization: *RViz is an engineering tool, not a video game.* The map canvas should be clean and unobstructed:
  - Never burn static text or legends over map pixels; let the coordinate frames and costmaps speak for themselves.
  - TF Alignment Verification: High-contrast overlay of red LiDAR scans directly over black occupancy grid walls allows instant visual confirmation that AMCL and EKF odometry are healthy and aligned.
  - Inflation Layer Clarity: Local costmap should clearly differentiate lethal obstacles (solid core) from inflation safety padding (gradient halo) so the operator sees why the local planner steers where it does.

### C. Yahboom Micro-ROS Pi 5 Robotic Car (`yahboom.net`)
* **Hardware Architecture:** Raspberry Pi 5 (Central SBC) connected over a 921,600 baud serial UART bus to an ESP32-S3 Micro-ROS expansion board.
* **Low-Voltage Motor Cutoff ($6.8\,\text{V}$):** The robot is powered by a 2S Li-ion battery ($7.4\,\text{V}$ nominal, $8.4\,\text{V}$ full). When the battery dips below $6.8\,\text{V}$, the expansion board's hardware protection disables the H-bridge motor drivers to prevent Li-ion cell damage while the Pi 5 continues running. Displaying battery voltage on the dashboard is essential to avoid diagnosing "phantom motor freezes."
* **Physical Safety (E-Stop):** Physical floor testing requires an immediate Emergency Stop button on the browser interface to halt moving motors without having to reach down to the physical switch.

## 3. Physical Robot Features to ADD

1. **`[🛑 EMERGENCY STOP]` Button (High-Priority Red):**
   - Immediately publishes zero velocity `geometry_msgs/Twist` (`linear.x = 0`, `angular.z = 0`) to `/cmd_vel`.
   - Sends cancellation to Nav2 navigator.
2. **`[⏹ Cancel Nav Goal]` Button:**
   - Clears active target and halts current plan.
3. **Live Battery Voltage Telemetry (`/battery`):**
   - Subscribes to `/battery` (`std_msgs/msg/UInt16`, where value 79 = 7.9V).
   - Shows live voltage badge with color coding:
     - 🟢 **Healthy:** $\ge 7.4\,\text{V}$
     - 🟡 **Moderate:** $7.0\,\text{V} - 7.3\,\text{V}$
     - 🔴 **Critical Warning:** $< 7.0\,\text{V}$ (Approaching $6.8\,\text{V}$ motor shutdown).
4. **Interactive Quick Waypoint Dispatchers:**
   - `[🏠 Dock Home]` $\to$ Sends Nav2 goal to `(0.08, 0.05, 0°)`
   - `[1️⃣ WP1 Runway]` $\to$ Sends Nav2 goal to `(0.40, 0.00, 0°)`
   - `[2️⃣ WP2 Curve]` $\to$ Sends Nav2 goal to `(0.70, 0.35, 90°)`
   - `[3️⃣ WP3 Return]` $\to$ Sends Nav2 goal to `(0.35, 0.15, 180°)`
5. **Dual LiDAR Topic Support:**
   - Auto-subscribes to both `/scan` and `/scan_downsampled` to ensure 100% plug-and-play operation with the physical robot's `scan_republisher`.
